## Descrição do Projeto

Este projeto consiste no desenvolvimento de um sistema simples de atendimento e realização de pedidos para uma lanchonete, utilizando a linguagem Python.

O sistema permite que o cliente informe seu nome, visualize o cardápio, escolha produtos e quantidades e acompanhe o valor total da compra.

Antes de finalizar o pedido, o cliente pode revisar a comanda, adicionar novos produtos ou remover produtos já selecionados.

Após a confirmação, o sistema calcula o desconto de acordo com o valor total da compra, solicita a forma de pagamento e apresenta o recibo final.

## Funcionalidades

- Identificação do cliente;
- Exibição do cardápio;
- Seleção de produtos por código;
- Escolha da quantidade;
- Cálculo do subtotal de cada produto;
- Cálculo do valor total da compra;
- Possibilidade de adicionar vários produtos;
- Validação de códigos e opções;
- Revisão do pedido;
- Adição de produtos durante a revisão;
- Remoção de produtos;
- Aplicação automática de desconto;
- Seleção da forma de pagamento;
- Apresentação do recibo final.

## Regras de Desconto

O sistema utiliza as seguintes regras:

- Compras abaixo de R$ 50,00: sem desconto;
- Compras de R$ 50,00 até R$ 99,99: 5% de desconto;
- Compras iguais ou superiores a R$ 100,00: 10% de desconto.

## Formas de Pagamento

O sistema permite selecionar:

1. Dinheiro
2. PIX
3. Cartão
